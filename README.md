# Análisis de Eficiencia de Ventas - Cadena de Tiendas
Este proyecto consiste en un análisis de datos integral realizado para identificar la unidad de negocio menos eficiente dentro de una cadena de cuatro tiendas. El objetivo final es proporcionar una recomendación basada en datos para una desinversión estratégica, permitiendo al propietario (Sr. Juan) capitalizar un nuevo emprendimiento.

## 📊 Resumen del Proyecto
El análisis integra métricas de ventas, costos logísticos y satisfacción del cliente para determinar qué tienda tiene el menor impacto financiero y estratégico en la organización.

## 📈 Hallazgos Clave
A través del análisis de las bases de datos unificadas, se identificaron los siguientes puntos:

* Distribución de Ingresos: Aunque la Tienda 1 lidera, la diferencia entre la mejor y la peor tienda es de solo un 2.5% en participación de ingresos.

* Correlación Logística: Se observó una relación positiva donde los costos de envío escalan proporcionalmente con el volumen de ventas, descartando ineficiencias logísticas aisladas.

* Desempeño por Categoría: La Tienda 4 muestra debilidad en categorías de alto ticket como Electrónicos, concentrando su volumen en artículos de menor margen.

## 📋 Conclusión y Recomendación
Se recomendó la venta de la Tienda 4. A pesar de tener una calificación de usuario aceptable (3.99), presenta el menor volumen de ingresos y el menor potencial de crecimiento en categorías clave de alto valor.
